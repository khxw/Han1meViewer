# 玻璃态 UI（Glassmorphism）设计规格

- 日期：2026-08-31
- 状态：已确认（用户逐段确认）
- 关联需求：软件 UI 升级为玻璃态，且与现有 UI 可切换

## 1. 背景与目标

Han1meViewer 现有 UI 为 Material3 纯色风格（10 个主题色预设 + 深/浅色 + AMOLED 纯黑）。用户希望新增"玻璃态 UI"：毛玻璃质感、通透轻盈，作为**可切换的独立主题**，默认不影响现有用户体验。

## 2. 需求决策记录

| 决策点 | 结论 | 依据 |
|---|---|---|
| 玻璃覆盖强度 | B 中度：顶栏、主要卡片、评论栏、底栏 | 视觉模拟对比后用户选定 |
| 背景处理 | A 氛围光：跟随主题色的渐变 + 柔和光斑 | 现有背景为纯色，玻璃需透出内容 |
| 默认状态 | **默认关闭**（经典 UI），设置里手动开启 | 老用户升级无感 |
| 形态 | **独立主题**（"界面风格"设置项），非叠加开关 | 用户明确选择 |
| 深浅色 | 跟随现有深色模式开关（深/浅两套玻璃参数） | 用户明确选择 |
| 技术路线 | Haze 2 库（真·毛玻璃） | 伪玻璃滚动可读性硬伤；自研成本过高 |

## 3. 设置项与主题系统

### 3.1 设置项

- 位置：设置页「主題顏色」同组，新增 **「界面风格」** 选择项
- 选项：`經典`（默认）/ `玻璃態`
- 存储：`Preferences` 新增 `uiStyle` 键（`"classic"` / `"glass"`），默认 `classic`
- 切换即时生效，无需重启（与主题色切换机制一致）

### 3.2 主题组合关系

`HanimeTheme` 内玻璃态与现有体系**正交组合**：

- 玻璃态 × 10 个主题色预设：氛围光跟随主题色（红主题红光氛围，动态取色同理）
- 玻璃态 × 深/浅色开关：深色玻璃 / 浅色玻璃两套参数
- **AMOLED 冲突规则**：玻璃态开启时 AMOLED 纯黑背景自动让位于氛围光（两者互斥，玻璃态优先）；玻璃态关闭后 AMOLED 恢复。玻璃态开启时在设置项下提示"AMOLED 純黑在玻璃態下不生效"

### 3.3 数据流

```
设置项「界面风格」→ Preferences.uiStyle
        ↓
HanimeTheme（读取 uiStyle）
        ↓
GlassThemeCompositionLocal（玻璃参数表：透明度/模糊度/边框色，深浅色各一套）
        ↓
玻璃容器组件（顶栏 / 悬浮底栏 / 抽屉 / 卡片 / 对话框 / 评论栏）
```

## 4. 视觉规格

### 4.1 氛围光背景（所有页面统一）

- 新组件 `GlassAmbientBackground`：主题色对角渐变（约 165°）+ 2~3 个柔和 radial 光斑
- 深色版：渐变尾端为深色 background；浅色版：尾端为浅色 background、光斑更淡
- 光斑颜色派生自 `primary` / `secondary` / `tertiary`
- 替换各页面根部的 `.background(MaterialTheme.colorScheme.background)`（玻璃态开启时）

### 4.2 玻璃容器参数（深/浅两套）

| 参数 | 深色玻璃 | 浅色玻璃 |
|---|---|---|
| 背景色 | `surfaceContainer` 55% 透明度 | `surfaceContainer` 72% 透明度 |
| 模糊 | 18px | 16px |
| 描边 | 白色 12% 透明度 1px | 白色 45% 透明度 1px |
| 圆角 | 维持组件现有圆角 | 维持现有圆角 |

### 4.3 玻璃化组件清单

**改造（改一处全 App 生效）**：
1. `HanimeScaffold` 页顶栏
2. `MainActivityScaffold` 悬浮底部导航栏
3. 侧边抽屉 `ModalDrawerSheet`
4. 通用卡片容器（视频网格卡片、收藏/历史条目卡）
5. `AlertDialog` / BottomSheet
6. 评论区输入栏（`CommentReplyBar`）
7. 设置页分组卡、各页面筛选/工具栏

**排除（保持现状）**：
- 视频播放器 UI（沉浸式黑底）
- 图片/封面本身
- 登录页、关于页等低频页（后续可跟进）

### 4.4 可读性保障

- 玻璃容器内文字保持 `onSurface` 原色，不在玻璃上叠加透明度
- 滚动列表透出的背景内容被模糊糊掉（选 Haze 而非伪玻璃的关键原因）

## 5. 技术实现

### 5.1 依赖

- 新增 `dev.chrisbanes.haze:haze:1.7.3` 与 `dev.chrisbanes.haze:haze-materials:1.7.3`（`libs.versions.toml`；实施核实：haze 无 2.x 稳定版（最新 2.0.0-beta02），haze-materials 无 2.x，故取双工件共有稳定版 1.7.3，Glass.kt 所用 API 已实测兼容）
- 项目 Compose BOM 2026.05 兼容；Haze 硬件加速、API < 31 自动降级（仅 tint 无 blur）

### 5.2 Haze 挂载结构

```
页面根 Box
 ├─ GlassAmbientBackground ← 挂 hazeSource(state)
 └─ 内容层
     ├─ 顶栏/底栏/抽屉/卡片/对话框
     │    └─ 容器 ← 挂 hazeEffect(state) { 半透明色 + blur + 描边 }
     └─ 普通内容（封面图、文字）
```

- 玻璃参数封装为 `Modifier.hanimeGlass(state, tint)` 扩展函数，一处定义全局复用
- 各组件容器色阶（surfaceContainerLow/High 等）统一映射到 `surfaceContainer` 后再套透明度，保证玻璃视觉一致
- `HazeState` 经 `CompositionLocal` 传递

### 5.3 兼容与降级

- Android 12 以下（RenderEffect 不可用）：Haze 自动降级无模糊，保留半透明 + 描边（轻玻璃）
- 性能：模糊 GPU 单次执行，氛围光为静态渐变零每帧开销；若低端机卡顿，设置页注明"建议中端以上设备"
- R8：Haze 自带 consumer rules，构建时验证

### 5.4 实施顺序

1. 主题层：`uiStyle` 设置项 + `HanimeTheme` 分支 + 玻璃参数 `CompositionLocal`
2. `GlassAmbientBackground` + 各页面根部背景替换
3. Haze 依赖 + `hanimeGlass` Modifier
4. 全局组件改造（顶栏 → 底栏 → 抽屉 → 卡片 → 对话框 → 评论栏）
5. 深浅色双套参数调校 + 低端机验证
6. 构建 arm64-v8a 真机验收

## 6. 测试与验收

- **回归（默认关闭）**：全部页面与现状一致；组件改造走"参数表为空时零变化"路径
- **玻璃态开启**：10 个主题色 × 深/浅色抽查首页/详情/设置/抽屉；滚动列表可读性；键盘弹起时评论栏玻璃与既有 IME 避让机制不回归
- **真机**：vivo 设备验证性能与模糊效果；低版本 Android 模拟器验证降级路径

## 7. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 玻璃容器与背景层级错挂导致无模糊 | 挂载结构图先行、每个组件改完单独视觉验证 |
| 浅色玻璃对比度不足 | 72% 不透明度 + 45% 白描边参数预调，真机实测后再微调 |
| 低端机滚动卡顿 | Haze 硬件加速 + 静态背景；必要时设置项注明设备建议 |
| 改造组件回归破坏既有行为（IME 避让、AppBar 锁定） | 默认关闭路径零变化；开启路径逐一验证评论栏/顶栏交互 |
